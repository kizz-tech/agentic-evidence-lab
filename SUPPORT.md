# Support

This project is an experimental open-source alpha with no support SLA.

- Usage questions and open-ended reproducibility help: use GitHub Discussions
  Q&A.
- Reproducible defects: use the bug report Issue Form.
- Methodology criticism with a specific target and requested disposition: use
  the evidence or methodology challenge Issue Form.
- Research ideas and third-party skill nominations: use GitHub Discussions
  Ideas until the proposal has a bounded decision and acceptance path.
- Vulnerabilities: use GitHub Private Vulnerability Reporting as described in
  `SECURITY.md`.
- Private data, credentials, and embargoed reports must not be posted publicly.

For reproducible defects, include the AEL version, operating system, Python
version, exact command, minimal fixture, and the distinction between expected
and observed behavior. See the [community workflow](docs/community-workflow.md)
for the boundary between Discussions, Issues, pull requests, and evidence.
