# Support

This project is an experimental open-source alpha with no support SLA.

- Usage questions and reproducibility problems: open a GitHub issue.
- Methodology criticism: use the methodology review issue template.
- Vulnerabilities: use GitHub Private Vulnerability Reporting as described in
  `SECURITY.md`.
- Private data, credentials, and embargoed reports must not be posted publicly.

Please include the AEL version, operating system, Python version, exact command,
minimal fixture, and the distinction between expected and observed behavior.
