# Completion Integrity task plan

This is the public pre-execution design declaration. Exact task, evaluator,
reference, regression, paraphrase, and private-canary bytes remain outside the
Git worktree. A future sanitized retired export would be a separately versioned
artifact and cannot replace or mutate the frozen private-pack identity.

## Population

The scored population contains eight small Python repository tasks. Six are
screening cases and two are untouched confirmation cases. Two additional
sacrificial baseline cases replay historically observed failure families,
establish headroom, and are excluded from every effect estimate. The eight
scored cases use fresh bytes; the confirmation pair was not used in
sacrificial calibration or task repair.

| `CI-01` | screening | requirement coverage | partial required work |
| `CI-02` | screening | requirement coverage | partial required work |
| `CI-03` | screening | requirement coverage | cross-surface synchronization |

| `CI-05` | screening | acceptance evidence | focal-fix regression |

| `CI-08` | confirmation | acceptance evidence | legitimate external blocker |

`CI-01` and `CI-04` additionally have task-instruction paraphrases. Those four
condition-crossed probe cells are non-primary and do not increase the
independent task count.

## Oracle contract

Every `TaskCaseRevision` binds the task instruction, initial fixture,
requirement IDs, deterministic evaluator, known-good state, plausible
incomplete state, regression-producing state, invalid evaluator state,
mechanism, role, and package digest. The no-call gate requires all eight task
oracles to distinguish all four states, with visible fixture checks passing
while owner acceptance rejects the pristine state.

The agent never receives the evaluator, reference, regression, dossier, role,
mechanism, stratum, pack, or confirmation metadata. The no-call gate passed all
32 known-state checks for private-pack revision 4 before its two excluded
headroom calls. Both headroom calls were false completions on the pinned strong
stack; no scored call had occurred when this declaration was written.
