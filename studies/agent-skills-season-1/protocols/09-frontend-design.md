# 09 — Frontend design

State: protocol draft; public activation calibration completed after an
evaluator correction; blinded human effectiveness evaluation remains unrun.

## Decision question

Does the exact pinned Anthropic `frontend-design` skill improve perceived
specificity and design quality while preserving accessibility, responsiveness,
and task success?

## Conditions and task design

- `B0`: identical frontend agent stack and factual brief without the skill.
- `S1`: `B0` plus exact frontend-design.
- `P1`: equal-context neutral design guidance is required because subjective
  preference can respond to any added creative direction.

Briefs cover distinct subjects and page jobs. Outputs use the same framework,
asset allowance, viewport matrix, and time budget. Human raters are blinded to
condition; deterministic accessibility and interaction gates run first.

## Measurements and decision

Primary: paired blinded preference among outputs that pass accessibility and
task-success gates. Secondary: subject specificity, hierarchy, responsive
behavior, performance, implementation defects, cost, and time. Report rater
agreement and ties. This cannot be reduced to a universal aesthetic score or
evaluated by the producing model alone.
