# Focused Change Verification adaptation pack

State: public adaptation pack; not a hidden or confirmatory benchmark.

Each task exposes a small Python repository and a user request. The visible
tests establish the starting contract. Evaluator tests remain outside the
fixture mounted for an agent run and execute only against the exported result
inside the offline container runner.

This pack is intended to debug the E3 pipeline and estimate operational
variance. Results from it cannot support a held-out generalization claim.
