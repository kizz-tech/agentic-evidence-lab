# Agentic Evidence Lab `v0.1.0-alpha.9`

Publication state is proven by the exact Git tag, exact-SHA CI run, release
manifest, verified assets, and GitHub prerelease. This note records the release
contract but does not replace that external evidence.

Alpha.9 is the first terminal empirical release after the claim-first method.
It asks whether one exact appended Completion Integrity prompt policy reduces
false declarations of completion on a pinned Codex stack and frozen task
population.

## Result first

The policy did not help on the admitted surface:

- 52/52 scheduled cells terminated validly;
- baseline false completion: `0.375`;
- treatment false completion: `0.375`;
- equal-task-weighted reduction: `0.000`;
- deterministic 80% task-cluster interval: `[0.000, 0.000]`;
- accepted-final-state rate: `0.375` in both conditions;
- false non-completion, indeterminate declaration, and critical failure: `0`
  in both conditions;
- eligible mechanisms: none;
- frozen disposition: `reject_exact_policy`.

All anti-abstention guardrails passed. The policy is rejected because it
produced no improvement, not because it increased silence or critical harm.
The result applies only to the exact policy, task population, model/runtime
stack, budget, and observation date.

## Prospective evidence chain

Alpha.9 completes the first AEL study with a hash-bound prospective Study
Quality Profile and full preflight-to-receipt lifecycle:

- an eight-task private pack spanning two mechanisms and four strata;
- deterministic task and evaluator audits plus a no-call discrimination gate;
- a zero-scored-call revision-3 freeze and owner action mapping;
- a 52-cell schedule with three repeats and four non-governing paraphrase
  probes;
- an append-only no-retry execution policy;
- a deterministic task-cluster uncertainty rule and predeclared guardrails;
- retained negative findings and a recorded-not-deployed rejection.

Commit `d0d506c67e48e1ec4e9921be74ae598bb06a9155` is the preregistration anchor.
Git establishes repository artifact ordering; it does not independently
timestamp private hosted calls.

## Public result and audit

The release adds:

- 52 normalized public Run Records and 521 measurements;
- the frozen effect decision, adoption record, receipt, freeze binding, and
  narrative report;
- a fifth claim-first result card with a contradicted governing effect claim;
- the `completion-integrity-prompt-policy-v1` audit adapter, which recomputes
  the terminal result from public measurements;

## Privacy and reproducibility boundary

Exact tasks, evaluator code, candidate workspaces, raw events, attempt journals,
authentication, and canaries remain outside Git and release archives. A public
checkout can validate the Contract graph, recompute the bounded decision, and
verify Git ordering. It cannot replay the historical provider behavior or
constitute independent replication.

## Direction after the null

The next release prioritizes a completed downstream outcome or genuinely
role-separated reproduction over another framework-only increment. A future
Completion Integrity candidate must materially change execution or verification
behavior and pass a new freeze; this release does not infer that tools or
workflow gates will succeed merely because the prompt-only policy failed.

## Compatibility

Alpha.9 changes none of the five Contract v0 schemas or previously released
evidence bytes. It remains pre-stable and makes no universal prompt, model,
transfer, production-outcome, or independent-replication claim.
