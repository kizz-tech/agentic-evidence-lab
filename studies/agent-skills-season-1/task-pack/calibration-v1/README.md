# Agent Skills Season 1 — public calibration pack

This pack contains one mechanics task per planned study. It calibrates fixture
copying, visible checks, separate acceptance evaluation, and study-specific
artifact shapes. It does not measure any third-party skill effect.

The health rule is uniform: the pristine fixture must pass its visible smoke
tests and fail its separate evaluator. An agent sees `fixture/` only;
`evaluator/` is mounted after the run.

The tasks deliberately remain small and public. Screening and confirmation
must use new, non-prescriptive tasks and separately frozen evaluators.
