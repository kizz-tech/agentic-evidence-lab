# Agentic Evidence Lab `v0.1.0-alpha.6`

Status: local development line; not tagged or published

The alpha.6 development line closes the first complete decision-governing AEL
loop. It admits one
exact public skill snapshot before scored work, runs a bounded matched Codex
pilot, applies a frozen effect rule, executes a preregistered owner policy, and
records a separate action and follow-up record.

## Result

The exact Superpowers `systematic-debugging` snapshot did not earn automatic
routing on four sanitized AEL real-shadow fixtures:

- eight of eight scheduled cells completed as valid;
- all four treatment activations were verified;
- all four matched pairs tied on final acceptance;
- baseline and treatment each accepted three of four tasks;
- one treatment critical failure triggered the frozen absolute safety gate;
- the owner action blocks only the exact tested revision/tree on the frozen
  Codex stack; no global install or removal occurred.

The baseline produced a critical failure on the same task. The evidence
therefore supports the conservative exact-version block but not a claim that
the skill caused harm, that systematic debugging is ineffective in general, or
that Superpowers is inferior.

## Prospective lifecycle

Experimental pilot-local records now bind and expose:

```text
admission → freeze → effect decision → adoption decision → action → follow-up
```

These are not new stable Contract v0 schemas. Contract v0 still consists of
concept, study manifest, run record, measurement set, and evidence receipt.
The public-results profile and projection policy move to `0.2` so current
lifecycle status is derived from exact public refs instead of profile-authored
prose.

## Audit

```bash
uv run ael study audit \
  --freeze studies/agent-skills-season-1/screening/systematic-debugging-real-shadow.freeze.json \
  --result studies/agent-skills-season-1/results/systematic-debugging-real-shadow-v1 \
  --decision-adapter systematic-debugging-real-shadow-v1 \
  --require-git-proof
```

The adapter validates 8 public run records and 80 measurements, reconstructs
the effect decision, checks the owner-policy hash chain, and verifies that the
freeze/admission bytes existed before result artifacts in Git. Git remains
artifact-order proof, not an independent timestamp for private model calls.

## Disclosed materialization repair

The frozen materializer generated the complete bundle but failed its final
Contract v0 check because it used the undeclared `partially_rerunnable` enum.
A single-use repair changed only that projection field to `rerunnable`, added a
receipt disclosure, and recomputed dependent hashes. The public deviation
record binds the original invalid receipt, frozen materializer, repair tool,
and unchanged effect decision. The audit reconstructs and verifies that repair.

## Boundaries

- Private sanitized tasks, raw events, candidate workspaces, and evaluator
  outputs remain withheld and hash-bound.
- Hosted Codex uses a reusable credential and remains restricted to exact,
  maintainer-reviewed content under explicit owner acceptance.
- One draw per condition and four tasks do not support stable cost, latency,
  transfer, or leaderboard claims.
- The result is maintainer-evaluated, not independently reproduced.
- The follow-up is scheduled; no downstream outcome is yet observed.
