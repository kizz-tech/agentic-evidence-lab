# Agentic Evidence Lab `v0.1.0-alpha.7`

Release channel: GitHub prerelease

Alpha.7 pauses new scored model work and strengthens the method used before a
study starts. It adds a deterministic measurement-quality preflight,
exposes honest quality facets on public result cards, and adds an evidence-gated
roadmap.

## Study Quality Preflight

The new pilot `ael.study-quality-profile/0.1-pilot` binds one exact Contract v0
Study Manifest plus:

- construct operationalization, target claim, claim ceiling, and falsifier;
- task provenance and audit evidence;
- evaluator scoring, calibration, error boundary, and adjudication;
- decision threshold, missing/invalid-cell policy, and uncertainty method or
  explicit `not_estimable` state;
- task count, repeats, order policy, nuisance factors, and declared reliability
  coverage;
- zero-scored-call and explicit freshness declarations.

`ael study preflight` validates all refs and hashes offline, checks Contract
identity and claim boundaries, emits deterministic JSON/Markdown, and returns a
failing exit status for blocked designs. One-repeat, non-random order,
`not_estimable`, and maintainer-only evaluation remain visible warnings rather
than dishonest universal prohibitions.

## Public result projection

The public-results/profile policy moves to `0.4`. Every card now exposes seven
non-compensating design-preflight facets: design class, task validity,
evaluator validity, sampling strength, reliability coverage, independence, and
assessment freshness.

All four existing studies are explicitly `not_assessed_historical`. Alpha.7
does not reconstruct a pre-run quality assessment from post-run artifacts. A
future profiled card must reference a conformant quality profile whose exact
study ID, revision, and manifest hash match its receipt.

The same projection revision removes two ambiguous public shortcuts:

- `catalog_state` now describes only whether a result is listed or withdrawn
  from the repository catalog; it does not claim a tag, GitHub release, or
  package publication;
- cards separately expose public graph verification, maintainer rerun
  capability, and linked independent replication instead of using the receipt
  label `rerunnable` as a headline.

The raw Contract v0 value remains available as bounded receipt metadata. All
four current result families, including Systematic Debugging, are deliberately
listed in the generated catalog. See the
[result-catalog decision](../decisions/2026-08-14-result-catalog-and-reproduction-semantics.md).

## Prospective binding

Admission `ael.study-admission/0.2-pilot` requires a hash-bound
`quality_profile_ref`. A future freeze binds the admission bytes transitively;
legacy admission `0.1-pilot` remains valid unchanged. Contract v0 still consists
of the same five `0.1` schemas.

## Roadmap and limits

The new [roadmap](../../ROADMAP.md) separates available capabilities, next
evidence, explorations, beta gates, and deferred non-goals. It is a
research-direction record, not a delivery promise.

Alpha.7 performs no new scored model calls and changes no frozen receipt,
manifest, run, measurement, freeze, or historical report bytes. A conformant
preflight does not prove scientific validity, private-call chronology,
independent replication, transfer, or production impact. A listed result is
not proof that alpha.7 itself has been tagged or published.
