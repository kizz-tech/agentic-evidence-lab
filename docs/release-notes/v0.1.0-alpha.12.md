# Agentic Evidence Lab `v0.1.0-alpha.12`

Alpha.12 publishes the first bounded AEL Coevolution Protocol Stage-0
foundation. It is a method and adversarial-policy release, not an empirical
agent-improvement result.

## What is included

- AEL-CEP `0.2-development` beside the unchanged five-object Contract v0.
- A pure deterministic policy kernel for evaluator/Builder release identity,
  evaluation bindings, append-only score lineage, replay classes, exposure,
  revocation, bridge/epoch decisions, per-claim independence, causal contrast
  eligibility, and custody-separated promotion.
- A strict file/schema adapter with bounded parsing, complete predecessor-chain
  checks, atomic materialization, exact check mode, and data-only rescoring.
- A deterministic A0–A5 no-effect simulator covering null, useful effects,
  shared blind spots, evaluator exploitation, leakage, optional stopping,
  missingness, drift, poisoning, critical failure, deletion, and forbidden
  effects.
- One frozen Stage-0 package with 204 content-addressed records and one
  dependency-bound `contrast_summary` seal.
- Dedicated CLI operations: `coevolution simulate`, `check`, and `rescore`.

## Public boundary

Alpha.12 supports the CLI and versioned protocol/bundle/schema/file contracts.
The `ael.coevolution*` Python modules are experimental package internals and do
not carry compatibility guarantees. This keeps the already reviewed three-
module design reversible without declaring 33 policy helpers to be a public
API.

## Claim ceiling

The deterministic package demonstrates only the materialized implementation
invariants and negative tests that were actually checked. It does not establish:

- real Builder, Evaluator, Challenger, anchor, or organizational independence;
- physical append-only storage, secret custody, access control, deletion, or
  recovery;
- evaluator construct validity or reliability;
- model or agent improvement;
- causal superiority, transfer, novelty, production safety, or downstream
  outcome;
- protection from a hostile process racing files in a shared directory.

No hosted model call or external effect is part of this release. Every modeled
effect attempt is `blocked / not_dispatched`.

## Compatibility

- Contract v0 schemas are unchanged.
- Released alpha.3–alpha.11 evidence remains byte-locked.
- The Stage-0 protocol, bundle, report, and README golden bytes are unchanged
  from the independently reviewed local candidate.
- AEL-CEP stays family-local and is validated with `ael coevolution check`, not
  generic `ael validate`.

The release decision and council record are in
[Alpha.12 AEL-CEP public boundary](../decisions/2026-08-30-alpha12-public-boundary.md).

## What comes next

The next evidence milestone is not prospective coevolution. AEL must first test
whether its decision surface improves action quality over a competent ordinary
note/checklist and govern one real Codex intervention through action and
outcome. AEL-CEP Stage 1 remains a retrospective append-only shadow with no
Builder rerun or promotion.
